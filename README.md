# Figma to Code — Beginner Web Development Project

## About the Project

This project is a beginner-level web development exercise created by translating a design from **Figma into a webpage using HTML and CSS**.

The primary goal was to gain hands-on experience with the fundamentals of frontend development while exploring the relationship between UI/UX design and web implementation. It served as an opportunity to understand how a visual design can be transformed into a structured and styled webpage using basic web technologies.

Rather than focusing on complex functionality, this project emphasizes learning, experimentation, and building a foundation in web development and interface design.

## Objectives

- Understand the fundamentals of HTML and CSS.
- Learn how to translate a Figma design into a webpage.
- Explore webpage structure, layout, spacing, and alignment.
- Experiment with typography, colours, and other visual design elements.
- Develop an understanding of basic user interface (UI) design principles.
- Gain practical experience working with frontend code.

## Technologies Used

- **HTML5** — For structuring the webpage and its content.
- **CSS3** — For styling, layout, typography, colours, and visual presentation.
- **Figma** — For the original UI design and visual reference.

## Key Learnings

Through this project, I gained practical experience in:

- Structuring webpages using HTML elements.
- Styling components and layouts using CSS.
- Understanding the relationship between design and development.
- Translating visual references into code.
- Working with spacing, alignment, typography, and colour combinations.
- Improving attention to detail while recreating a design.
- Building confidence in writing frontend code from scratch.

## Getting Started

To view the project locally:

1. Clone this repository:

   ```bash
   git clone <your-repository-url>
   ```

2. Navigate to the project folder:

   ```bash
   cd <your-project-folder>
   ```

3. Open `index.html` in your browser.

   Alternatively, use the **Live Server** extension in Visual Studio Code for a convenient development experience.
